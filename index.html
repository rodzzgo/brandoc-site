BranDoc

Software para consultório que funciona sem internet.

Projeto em desenvolvimento (prova de conceito). Ainda não está disponível para uso clínico.

O que é

O BranDoc é um software para consultórios médicos que guarda os dados no próprio computador do consultório. Ele atende sem rede, e os computadores do consultório se sincronizam entre si pela rede local.

Como o BranDoc usa o Google Drive

Quando o médico liga a sincronização pela nuvem, o BranDoc usa o Google Drive da conta escolhida como meio de transporte entre os computadores do consultório:

  • pede só a permissão drive.file: enxerga apenas os arquivos que ele mesmo criou, nunca o resto do Drive;
  • grava numa pasta visível chamada Brandoc;
  • os arquivos são cifrados e assinados no computador antes do envio: o Google e o desenvolvedor não conseguem ler o conteúdo;
  • não há servidor do BranDoc no meio: os dados vão do computador direto para o Drive da própria conta.
